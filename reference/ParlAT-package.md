# ParlAT: A wrapper for the API of the Austrian Parliament

The ParlAT package wraps the API of the Austrian Parliament and seeks to
provide an easy way for R users to access the available Open Data. This
includes, but is not limited to, data on past and current MPs, plenary
sessions, or protocols.
